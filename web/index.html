      Keep the companion running, then connect your browser once.

      1. Open your Brave, Chrome, or Edge extension manager, turn on Developer mode, then choose Load unpacked.
      2. Select the extension folder in this project.
      3. Copy the code below. In your browser toolbar, open Extensions → Interlude, paste it, and click Connect.
      4. In that popup, choose your media tab and grant access to its site. Reload an existing media tab once after installing or updating the extension.

      Connect Codex

      Run these commands from the project folder:

      npm run hooks:preview
      npm run hooks:install

      Open the Codex CLI in this project, type /hooks, and review and trust the Interlude hooks. If your next desktop prompt is not detected, try a fresh task in this project or restart Codex after current work finishes.

      The hooks never approve commands. They only report task events locally. Existing hooks are preserved.
