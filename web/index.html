      Keep the companion running. The extension pairs with it automatically.

      1. Open your Brave, Chrome, or Edge extension manager, turn on Developer mode, then choose Load unpacked.
      2. Select the extension folder below. Interlude generates the path below for this computer.
      3. Reload Interlude after an update, then open it from the browser toolbar. It should show Connected to the local companion.
      4. Choose your media tab and click Use this tab. Your browser asks for access only to that selected site.

      Open the Codex CLI, type /hooks, and review and trust the Interlude hooks. If your next desktop prompt is not detected, try a fresh task or restart Codex after current work finishes.
